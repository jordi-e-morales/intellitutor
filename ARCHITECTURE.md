  Project Summary: IntelliTutor

  IntelliTutor is an AI-powered educational tutoring system that uses RAG (Retrieval Augmented Generation) to provide personalized tutoring to students. It combines:

  - Flask web backend with authentication
  - CrewAI for agent orchestration
  - Qdrant vector database for semantic search
  - PostgreSQL for relational data
  - Ollama for local LLM inference
